HALF-DAY TUTORIAL COMPANION

視野データ解析｜初学者向け用語集

添付HTML・Jupyterノートブックに対応。略語の正式名称から、コードの変数名まで、90語を検索できます。

この教材でしていること：30人の360回の視野検査から、過去3回の測定を用いて次の1回の52地点の感度（dB）を予測し、21人で学習・9人で評価します。これは病気の有無や長期進行の予測ではありません。
★は優先的に覚える用語。英語の正式名称や一般的な概念については、教材外の公開資料・一般的な用語説明による補足も含みます。
MS ≠ MD単純平均と、正常値からの偏差は別の指標。
0 dB ≠ 欠測ゼロも視野計で記録された数値。
FPR ≠ 診断の偽陽性率今回は検査中の反応品質の指標。
270窓 ≠ 270人30人の繰り返し測定から作成。
実測値 ≠ 真の感度予測対象にも測定ノイズが含まれる。
90語を表示中

① 視野検査・眼科の略語

GAP

★ 優先第0章

Gaze Analyzing Perimeter

ファインデックスの「視線分析型視野計」の製品名。視線の動きを解析して視野を検査する。

この教材では 本教材ではGAPの生データを解析しない。HFA由来の別の公開データを使う。

HFA

★ 優先第0・1章

Humphrey Field Analyzer

ハンフリー視野計。光刺激への反応から視野の感度を測る標準的な自動視野計。

この教材では この教材の公開データはHFA由来。GAPと同一装置ではない。

VF

第0・7章

Visual Field

視野。目を動かさずに見える範囲・その場所ごとの機能を意味する。

この教材では 「VF検査」は視野検査。「眼底写真」とは異なる。

OD

★ 優先第1・6章

Oculus Dexter（ラテン語）

右眼。検査表の `eye` 列に出る。

この教材では この資料のODは右眼で、ソフトウェアの他の略語を意味しない。

OS

★ 優先第1・2・6章

Oculus Sinister（ラテン語）

左眼。検査表の `eye` 列に出る。

この教材では 左眼も図では右眼基準の座標にそろえて表示する。

dB

★ 優先第1・2・5章

decibel（デシベル）

刺激検出の閾値に対応する視野感度の対数尺度。一般に視野計では値が大きいほど弱い刺激を検出できる。

この教材では 「0 dB」は欠測を意味しない。dBの平均と光強度の平均は同じでない。

FPR / fpr

★ 優先第1章

False Positive Rate

視野検査で刺激がないのに反応するなどの偽陽性反応の割合。

この教材では 病気の有無を判定する分類器の偽陽性率と混同しない。資料中のfprは全件0だが、検査が完全だった根拠にはならない。

FNR / fnr

★ 優先第1章

False Negative Rate

本来見えると見込まれる刺激に反応しなかった割合。

この教材では 疾患の診断における偽陰性率ではなく、検査中の反応の信頼性に関する値。

FL / fl

★ 優先第1・6章

Fixation Loss(es)

固視不良。検査中に注視点から視線が外れた可能性を示す指標。

この教材では この教材では値を点検するが、予測の入力特徴には使わない。

BS / bs

★ 優先第1章

Blind Spot

盲点。視神経乳頭のため視覚受容が成立しない視野位置。

この教材では 本データでは盲点付近の l26、l35 を位置定義に基づき除く。低い値を見て恣意的に除いたのではない。

MS

★ 優先第2章

Mean Sensitivity

平均感度。今回扱う52個の視野感度（dB）の算術平均。

この教材では MDと違う。MSを正常値補正済みの指標と解釈しない。

MD

★ 優先第2章

Mean Deviation

平均偏差。年齢などに応じた正常期待値と比較して視野全体のずれを要約する指標。

この教材では この教材で計算している52点の単純平均（MS）はMDではない。

GPA

★ 優先第1章

Guided Progression Analysis

HFA等で使われる、視野検査の経時的な変化・進行を判定する解析機能。

この教材では 元の研究にGPAが登場するが、この教材はそのGPA解析を再現しない。

24-2

第1・7章

視野検査の測定パターン名

中心視野を一定の格子状の位置で測るHFAの代表的な検査パターン。

この教材では 「24 引く 2」という計算式ではない。資料名の 24d2 と関連する。

GazeBase

第7章

データセットの固有名

複数人の視線・眼球運動の時系列を含む公開データ。

この教材では 今回の実習に同梱されていない。第7章で将来の発展先として紹介される。

UWHVF

第7章

University of Washington Humphrey Visual Field（データセット名）

ワシントン大学の実臨床HFA視野検査をまとめた公開データ。

この教材では 今回使用するvisualFieldsデータとは別物。第7章で追加候補として紹介される。

l1〜l54

★ 優先第1章

視野位置の列番号

1回の検査で記録した54地点の感度を格納するデータ列名。

この教材では `l` の英語の正式展開はこの教材にない。l26・l35除外後は52点。

② 解析・統計・機械学習の用語

QC

★ 優先第1章

Quality Control

品質管理・品質確認。患者ID、日付、欠損、重複、不自然な固定値などを調べる。

この教材では QCを行っただけで測定が臨床的に正確と証明されたわけではない。

PoC

★ 優先第0・6章

Proof of Concept

概念実証。アイデアを小規模な試作で実際に動かし、実現可能性を確かめること。

この教材では 製品化・臨床利用可能性の実証まで終えたという意味ではない。

MAE

★ 優先第0・5章

Mean Absolute Error

平均絶対誤差。予測値と実測値の差の絶対値を平均する。例：3 dBと5 dBの誤差は2 dB。

この教材では この教材の主要な評価指標。小さいほど「次回に観測された値」に近い。

CI

★ 優先第5章

Confidence Interval

信頼区間。データが変わった場合の推定値の不確実さを表すための区間。

この教材では 本教材の95%区間は9患者を単位としたpaired bootstrapのpercentile区間。0を含んでも同等性の証明ではない。

SVD

★ 優先第4章

Singular Value Decomposition

特異値分解。行列を分解する線形代数の手法。

この教材では `Ridge(..., solver="svd")` で係数を計算する方法の指定。視野計の略語ではない。

Ridge回帰

★ 優先第4章

Ridge Regression

線形回帰の係数が大きくなりすぎないよう罰則を加えた方法。

この教材では モデルは104入力→52出力。Ridgeが単純平均を上回る保証はない。

alpha / α

★ 優先第0・4章

正則化係数（Ridgeの調整パラメータ）

Ridge回帰で「係数を小さく抑える強さ」を決める数値。大きいほど抑制が強い。

この教材では この教材は `ALPHA=10.0` に固定。評価9患者の結果を見て変更しない。

正則化

第4・7章

Regularization

モデルを複雑にしすぎないよう制限して、未知データへの過学習を抑える工夫。

この教材では 正則化したから必ず高精度になるわけではない。

過学習

★ 優先第4章

Overfitting

学習データの偶然の特徴に合わせすぎ、未知の人ではうまく予測できないこと。

この教材では 独立患者が21人と少ないのに入力特徴104個を使うため注意する。

ベースライン

第4章

Baseline（基準法）

高度なモデルと比較するための、単純で説明しやすい方法。

この教材では ここでは `last`（前回値）と `mean3`（3回平均）が比較の基準。

特徴量

★ 優先第3章

Feature

予測に使う入力側の数値。過去の測定値から計算する。

この教材では この教材のXは、52点の3回平均＋52点の前回平均との差で合計104個。

目的変数

★ 優先第3章

Target / Label

モデルが予測しようとしている数値。

この教材では ここでは次回に記録された52点の感度。緑内障の有無や真の感度ではない。

スライディングウィンドウ

★ 優先第3章

Sliding Window

時系列の連続する一定数のデータを少しずつずらして入力を作る方法。

この教材では 1〜3回→4回、2〜4回→5回…で、12検査から各人9窓。

リーク

★ 優先第3章

Data Leakage

予測時には知り得ない未来の情報や、評価側の情報が学習側に紛れ込むこと。

この教材では 全12回平均をXに使う、評価データでStandardScaler.fitするなどが問題になる。

グループ分割

★ 優先第2・3章

Group Split

同一患者の記録が学習用と評価用の両方に入らないように分けること。

この教材では 21患者を学習、9患者を評価。同じ患者の9窓は独立した9人分の証拠ではない。

ホールドアウト

第2・5章

Held-out Test Set

モデル構築や設定変更には使わず、最後に評価するため残すデータ。

この教材では 本教材では未学習の9人。評価後にalphaを調整すれば、独立した最終評価としての意味が薄れる。

マクロ平均

★ 優先第5章

Macro Average

グループ別に平均したあと、そのグループを等しい重みで平均する集計。

この教材では 患者別MAEを計算し9人を等しく重みづける。患者ごとの回数差があっても患者を等しく扱える。

paired bootstrap

★ 優先第5章

対応のあるブートストラップ

同じ患者に対する2モデルの誤差の差を作り、患者単位で復元抽出して差の不確実性を調べる。

この教材では 52点や81窓を独立した患者として再抽出しない。評価は9人のみで不確実。

信頼区間95%

第5章

95% interval

同様の手順でデータを取り直したときの推定のばらつきを表現する区間。

この教材では 各区間に「真値が95%の確率で入る」と単純に解釈するのは頻度主義の定義として不正確。

感度帯

第5章

Sensitivity Band

予測前に分かっている過去3回平均の感度で地点をグループ分けすること。

この教材では 15 dB・25 dBは教材での便宜的な境界。重症度の診断基準ではない。

交差検証

第7章

Cross-validation

学習データの内部で分割を繰り返し、モデルの設定や安定性を確認する方法。

この教材では 発展課題では患者単位のグループ交差検証が提案されている。

GroupShuffleSplit

★ 優先第2章

scikit-learnのグループ単位分割器

グループIDをそろえて学習と評価に分けるクラス。

この教材では `groups=df["id"]` により同一患者を両側に置かない。

StandardScaler

★ 優先第3・4章

平均・標準偏差による標準化器

特徴ごとに学習データの平均と標準偏差を求め、数値の尺度をそろえる。

この教材では 評価患者で `fit` せず、学習患者で得た値を評価患者に適用する。

Pipeline / make_pipeline

★ 優先第4章

前処理とモデルを連結する仕組み

標準化→Ridge回帰を1つのモデルとして扱う。

この教材では 学習・予測の手順のずれやリークを防ぎやすい。

fit / predict

★ 優先第4章

学習する／予測する

`fit(X,Y)` は係数などを決め、`predict(X)` は学習済みの規則で予測する。

この教材では 評価データに対して `model.fit` してはいけない。

shape / axis

★ 優先第3章

配列の形／計算する軸

`shape` は各次元の個数、`axis` は平均などを取る方向。

この教材では `history.mean(axis=1)` は3回の検査方向に平均し、270×52へ。

groupby / sort_values

第1・3章

グループ化／値で並べ替え

患者ごとにまとめて処理する／日付順にそろえる。

この教材では 同一人物の時系列を正しく組み立てるために使用。

loc / iloc

第1・2章

ラベル／位置での行列選択

pandasの `df.loc[...]` は名前で指定、`df.iloc[...]` は順番で指定。

この教材では 例：`df.iloc[0]` は最初の行。視野の `locs` と混同しない。

対象回の固視不良率／検査間の日数

実測回の品質や日付の異常を後から調べるための変数。

flags / status

第6章

確認フラグ／処理状態

入力や予測値が想定範囲外なら理由と状態を返す。

この教材では `review` は「確認が必要」の意味であり、診断結果ではない。

assert / ValueError

第1〜6章

条件を確認／入力不正のエラー

`assert` は前提チェック、`raise ValueError` は不適切な入力を拒否する。

この教材では 患者混在・日時重複・欠損値を黙って受け取らないための工夫。

3つの配列を読めれば、コードの核心が分かります

history.shape == (270, 3, 52)  # 270予測窓 × 過去3回 × 52点
X.shape       == (270, 104)    # 52点の平均 + 52点の直近平均との差
Y.shape       == (270, 52)     # 次回の実測52点

例えば、ある地点の次回測定が20 dB、予測が24 dBなら絶対誤差は4 dBです。これを患者ごとにまとめ、9患者で等しく平均したのが教材の主要指標（患者マクロMAE）です。
